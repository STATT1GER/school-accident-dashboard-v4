# 학교안전 사고경로 관제 대시보드 v4

학교안전사고의 **사고시간 → 사고장소 → 사고 당시 활동 → 사고형태** 흐름을 중심으로 반복 경로와 개입 지점을 보여주는 Streamlit UI 프로토타입입니다.

## v4 핵심 방향

- 단순 사고 건수 비교보다 **사고 반복 경로를 우선** 표시합니다.
- 특정 미래 날짜나 개인의 사고 발생을 예측하는 모델이 아닙니다.
- 사고심각도는 보상·진단 근거가 없으므로 사용하지 않습니다.
- 실제 자료에 없는 층 정보는 화면과 분석에서 사용하지 않습니다.
- 상대 사고집중도와 추천 개입 지점을 통해 시간·공간 관리의 우선순위를 보여줍니다.

## 데이터 안내

이 프로젝트에는 실제 학교안전사고 원자료가 포함되어 있지 않습니다.

- `data/sample.csv`는 합성 예시 데이터입니다.
- 실제 학교명, 학생정보, 실제 사고ID, 개별 사고기록을 포함하지 않습니다.
- 지도는 실제 학교와 관계없는 `assets/school_map.png`의 가상학교 1층 배치도입니다.
- 지도상의 좌표는 사고장소 범주를 가상 배치도에 보여주기 위한 재현 가능한 시연 좌표이며 실제 사고 위치가 아닙니다.

## 상대 사고집중도

```text
상대 사고집중도 = 해당 범주의 사고 건수 ÷ 선택 조건 내 최대 사고 건수 × 100
```

선택한 범위에서 가장 많은 시간 또는 공간을 100으로 두는 비교지표입니다. 학생 수, 공간 이용량, 통행량과 체류시간이 반영되지 않았으므로 실제 사고확률이나 절대적인 위험도를 뜻하지 않습니다.

## 화면 구성

1. **메인 화면**
   - 사고 반복 경로 중심 메시지
   - 가상학교 1층 안전지도
   - 학교지도와 사고분석으로 연결되는 2개 관제 화면

2. **학교지도**
   - 일과 구간 선택
   - 가상학교 1층 지도 위 상대 사고집중도 히트맵
   - 공간적 개입 우선순위와 지도 기반 대응 제안

3. **사고분석**
   - 사고경로 → 시간 분석 → 장소 분석 → 활동·형태 순서
   - 전체·저학년·고학년 사고 반복 경로
   - 간단 Sankey / 전체 범주 Sankey
   - 상위 사고경로와 추천 개입 지점
   - 핵심 위험시간·핵심 위험장소·우선 개입 시점
   - 층별 분포 없이 장소 분포를 전체 너비로 제공

## 실행 방법

프로젝트 폴더에서 PowerShell을 열고 실행합니다.

```powershell
uv sync
uv run python -m streamlit run app.py
```

또는 기존 Python 환경에 `requirements.txt`를 설치한 뒤 실행합니다.

```powershell
pip install -r requirements.txt
python -m streamlit run app.py
```
